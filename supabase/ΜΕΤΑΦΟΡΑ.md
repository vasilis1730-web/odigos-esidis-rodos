**Authentication → Users → Add user** (email + προσωρινός κωδικός,
τσεκάρετε *Auto Confirm User*). Το προφίλ φτιάχνεται μόνο του με ρόλο
«Προβολή μόνο».


## 4. Μεταφορά των 9 φακέλων ✔

Έγινε. Οι 9 φάκελοι (3 ενεργοί, 6 αρχειοθετημένοι) και οι 21 εγγραφές
ιστορικού είναι στο νέο project, με τις αρχικές ημερομηνίες και το
`updated_by_email` άθικτα. Το `created_by` έμεινε κενό: οι παλιοί λογαριασμοί
(`vasilis1730@gmail.com`, `diakolios@rhodes.gr`) δεν υπάρχουν στο νέο project.
Η εφαρμογή δεν το εμφανίζει πουθενά.

Τα βήματα, για αναφορά:

**α) Στο ΠΑΛΙΟ project** (`hafaxrebjzootjzzqkzx`) → SQL Editor:

```sql
select jsonb_build_object(
  'folders', (
    select coalesce(jsonb_agg(to_jsonb(x)), '[]'::jsonb) from (
      select f.id, f.sector, f.title, f.state, f.status,
             f.created_at, f.updated_at, f.updated_by_email,
             cu.email as created_by_email
        from public.esidis_folders f
        left join auth.users cu on cu.id = f.created_by
    ) x),
  'logs', (
    select coalesce(jsonb_agg(to_jsonb(y)), '[]'::jsonb) from (
      select l.folder_id, l.action, l.note, l.at,
             bu.email as by_email
        from public.esidis_folder_log l
        left join auth.users bu on bu.id = l.by_user
    ) y)
) as dump;
```

Αντιγράψτε ολόκληρο το αποτέλεσμα (ένα μεγάλο JSON).

**β) Στο ΝΕΟ project** → SQL Editor. Επικολλήστε το JSON στη θέση που δείχνει
το σχόλιο και τρέξτε:

```sql
alter table public.esidis_folders disable trigger esidis_folders_touch;

with src as (select '<<< ΕΔΩ ΤΟ JSON >>>'::jsonb as j)
insert into public.esidis_folders
  (id, sector, title, state, status, created_at, updated_at,
   created_by, updated_by_email)
select (f->>'id')::uuid,
       f->>'sector',
       f->>'title',
       coalesce(f->'state', '{}'::jsonb),
       coalesce(f->>'status','active'),
       (f->>'created_at')::timestamptz,
       (f->>'updated_at')::timestamptz,
       (select id from auth.users u where u.email = f->>'created_by_email'),
       f->>'updated_by_email'
  from src, jsonb_array_elements(src.j->'folders') f
on conflict (id) do nothing;

with src as (select '<<< ΤΟ ΙΔΙΟ JSON >>>'::jsonb as j)
insert into public.esidis_folder_log (folder_id, action, note, at, by_user)
select (l->>'folder_id')::uuid,
       l->>'action',
       l->>'note',
       (l->>'at')::timestamptz,
       (select id from auth.users u where u.email = l->>'by_email')
  from src, jsonb_array_elements(src.j->'logs') l;

alter table public.esidis_folders enable trigger esidis_folders_touch;

-- έλεγχος: πρέπει να δείξει 9 φακέλους και 21 εγγραφές ιστορικού
select (select count(*) from public.esidis_folders)    as folders,
       (select count(*) from public.esidis_folder_log) as logs;
```

Αν κάποιος `created_by_email` δεν υπάρχει στο νέο project, το πεδίο μένει κενό.
Ο φάκελος και τα δεδομένα του μεταφέρονται κανονικά.
