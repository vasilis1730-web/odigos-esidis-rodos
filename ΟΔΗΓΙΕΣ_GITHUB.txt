ΠΡΙΝ ΑΠΟ ΟΛΑ: ΑΠΟΣΥΜΠΙΕΣΤΕ

Μην ανοίξετε το index.html μέσα από το ZIP. Τα Windows σας αφήνουν να
μπείτε στο ZIP σαν να είναι φάκελος, αλλά τότε εξάγουν προσωρινά μόνο
το ένα αρχείο που ανοίγετε. Η αρχική σελίδα θα φανεί κανονικά και μετά
τα κουμπιά θα βγάζουν "page not found".

Σωστά: δεξί κλικ στο ZIP -> "Εξαγωγή όλων" -> ανοίξτε το index.html
από τον φάκελο που θα προκύψει.

ΑΝΕΒΑΣΜΑ ΣΤΟ GITHUB PAGES

ΔΙΑΔΡΟΜΗ Α — ΔΗΜΟΣΙΟ REPOSITORY (πιο απλή, δωρεάν)

1. github.com -> New repository
   Όνομα: odigos-esidis-rodos
   Επιλέξτε "Public"  (το Pages στο δωρεάν πλάνο θέλει δημόσιο)
   Μην προσθέσετε README, το έχουμε ήδη.

2. Στη σελίδα του repository πατήστε "uploading an existing file".
   Σύρετε ΟΛΑ τα αρχεία του φακέλου, μαζί με το .nojekyll.
   ΠΡΟΣΟΧΗ: αν δεν βλέπετε το .nojekyll, ενεργοποιήστε την προβολή
   κρυφών αρχείων. Χωρίς αυτό το Pages μπορεί να μη σερβίρει σωστά.
   Πατήστε "Commit changes".

3. Settings -> Pages
   Source: "Deploy from a branch"
   Branch: main    Folder: / (root)
   Save.

4. Σε 1-2 λεπτά ο σύνδεσμος εμφανίζεται στην ίδια σελίδα:
   https://TO-ONOMA-SAS.github.io/odigos-esidis-rodos/

ΔΙΑΔΡΟΜΗ Β — ΙΔΙΩΤΙΚΟ REPOSITORY (αν δεν θέλετε να φαίνεται ο κώδικας)

1. Φτιάξτε το repository ως "Private" και ανεβάστε τα αρχεία όπως πάνω.
2. Πηγαίνετε στο dash.cloudflare.com -> Workers & Pages -> Create -> Pages
   -> Connect to Git -> επιλέξτε το repository.
3. Build command: αφήστε κενό.  Output directory: /
4. Save and Deploy. Παίρνετε σύνδεσμο .pages.dev
Κάθε commit ανεβαίνει αυτόματα. Ο κώδικας μένει ιδιωτικός.

ΜΕΤΑ ΤΟ ΑΝΕΒΑΣΜΑ

- Ανοίξτε τον σύνδεσμο, επιλέξτε ενότητα.
- Πάνω πάνω: "Σύνδεση στους κοινούς φακέλους".
- Δώστε το υπηρεσιακό email και τον κωδικό που ήδη έχετε στην
  εφαρμογή Προμηθειών του Δήμου.
- "Φάκελοι υπηρεσίας" -> δημιουργήστε τον πρώτο φάκελο.

ΔΙΑΧΕΙΡΙΣΗ: ΡΟΛΟΙ, ΔΙΑΓΡΑΦΗ, ΝΕΟΙ ΧΡΗΣΤΕΣ

ΠΟΙΟΣ ΕΙΝΑΙ ΔΙΑΧΕΙΡΙΣΤΗΣ
Ο ρολος οριζεται στη βαση, στη στηλη role του πινακα profiles.
Σημερα υπαρχει ΕΝΑΣ διαχειριστης: vasilis1730@gmail.com
Οι υπολοιποι 14 λογαριασμοι εχουν ρολους unit_user, viewer, central.
ΟΛΟΙ βλεπουν και δουλευουν κανονικα τους κοινους φακελους. Ο ρολος
admin δινει επιπλεον μονο δυο πραγματα: διαγραφη αρχειοθετημενων
φακελων και διαχειριση χρηστων.

ΠΟΥ ΕΙΝΑΙ Η ΔΙΑΓΡΑΦΗ
1. Συνδεθειτε με λογαριασμο διαχειριστη.
2. Πανω πανω: Φακελοι υπηρεσιας.
3. ΚΑΤΩ ΔΕΞΙΑ στο παραθυρο: κουμπι Εμφανιση αρχειου.
4. Εμφανιζεται ενοτητα ΑΡΧΕΙΟΘΕΤΗΜΕΝΟΙ με κουμπια Επαναφορα και
   κοκκινο Διαγραφη.
Ενεργος φακελος ΔΕΝ διαγραφεται. Πρωτα αρχειοθετειται.

ΔΙΑΧΕΙΡΙΣΗ ΧΡΗΣΤΩΝ
Ο διαχειριστης βλεπει πανω πανω επιπλεον κουμπι Χρηστες.
Απο εκει: αλλαγη ρολου και ενεργοποιηση/απενεργοποιηση λογαριασμου.
Δεν μπορειτε να αλλαξετε τον δικο σας ρολο (προστασια απο κλειδωμα).

ΔΗΜΙΟΥΡΓΙΑ ΝΕΟΥ ΧΡΗΣΤΗ
Δεν γινεται μεσα απο τον οδηγο, για λογους ασφαλειας. Γινεται ως εξης:
1. supabase.com/dashboard -> project promitheies-dimou-rodou
   (η απευθειας απο το κουμπι μεσα στην οθονη Χρηστες)
2. Authentication -> Users -> Add user
3. Email + password. Τσεκαρετε Auto Confirm User.
4. Το προφιλ δημιουργειται ΑΥΤΟΜΑΤΑ με ρολο viewer και ενεργο.
5. Γυριζετε στον οδηγο -> Χρηστες -> αλλαζετε τον ρολο αν χρειαζεται.
6. Δινετε στον συναδελφο email και κωδικο.

ΑΠΕΝΕΡΓΟΠΟΙΗΣΗ ΑΝΤΙ ΔΙΑΓΡΑΦΗΣ ΧΡΗΣΤΗ
Για αποχωρηση υπαλληλου, μην διαγραφετε τον λογαριασμο. Πατηστε
Απενεργοποιηση. Χανει αμεσως την προσβαση, αλλα παραμενει το ιστορικο
του για το ποιος ενημερωσε ποιον φακελο.

ΠΩΣ ΔΟΥΛΕΥΕΙ Ο ΦΑΚΕΛΟΣ ΕΡΓΟΥ

Ο φάκελος ΕΙΝΑΙ το έργο. Δεν υπάρχει ξεχωριστή "τοπική δουλειά" που
μετά την ανεβάζετε κάπου.

1. Πατάτε "Νέο έργο". Ζητά αμέσως ονομασία και φτιάχνει τον φάκελο.
2. Από εκείνη τη στιγμή, ΟΤΙΔΗΠΟΤΕ συμπληρώνετε αποθηκεύεται μόνο του
   μέσα σε δύο δευτερόλεπτα: στοιχεία, βήμα ροής, σημειώσεις, είδη,
   ολοκληρωμένα βήματα, ειδικοί κλάδοι.
3. Πάνω πάνω βλέπετε πάντα την κατάσταση:
   "Αλλαγές - αποθηκεύονται σε λίγο" / "Αποθήκευση..." / "Αποθηκεύτηκε"
4. Οποιοσδήποτε συνάδελφος ανοίγει τον φάκελο βρίσκει ακριβώς τα ίδια
   στοιχεία ΚΑΙ το ίδιο σημείο της διαδικασίας.

ΑΝ ΔΥΟ ΑΤΟΜΑ ΔΟΥΛΕΨΟΥΝ ΤΑΥΤΟΧΡΟΝΑ
Η αυτόματη αποθήκευση σταματά και εμφανίζεται προειδοποίηση με το όνομα
του άλλου. Διαλέγετε "Φόρτωση της δικής του έκδοσης" ή "Κράτα τη δική
μου". Τίποτα δεν χάνεται σιωπηλά.

ΧΩΡΙΣ ΣΥΝΔΕΣΗ
Αν πατήσετε "Νέο έργο" χωρίς να είστε συνδεδεμένοι, σας προειδοποιεί ότι
δεν θα το βλέπουν οι συνάδελφοι και σας προτείνει να συνδεθείτε πρώτα.

ΠΛΟΗΓΗΣΗ ΜΕΣΑ ΣΤΗΝ ΕΦΑΡΜΟΓΗ
Πάνω αριστερά σε κάθε ενότητα υπάρχουν δύο κουμπιά:
  "<- Επιλογή ενότητας"  επιστροφή στην αρχική σελίδα
  "Μετάβαση: ..."        απευθείας άνοιγμα της άλλης ενότητας
Αν έχετε αλλαγές που δεν έχουν αποθηκευτεί στους κοινούς φακέλους,
η εφαρμογή ρωτάει πριν σας βγάλει έξω.

ΕΝΗΜΕΡΩΣΗ ΑΡΓΟΤΕΡΑ
Ανεβάζετε το νέο αρχείο πάνω στο παλιό και κάνετε commit. Κρατάτε
ιστορικό και μπορείτε να γυρίσετε πίσω από το Commits.
