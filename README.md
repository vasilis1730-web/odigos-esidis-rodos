# Ενιαίος Οδηγός ΕΣΗΔΗΣ — Δήμος Ρόδου

Βοήθημα οργάνωσης διαγωνιστικών διαδικασιών του ν. 4412/2016, σε δύο ενότητες:

| Ενότητα | Αρχείο | Καλύπτει |
|---|---|---|
| Δημόσια Έργα | `dimosia_erga.html` | Ανοικτός διαγωνισμός, απευθείας ανάθεση, διαπραγμάτευση |
| Προμήθειες & Γενικές Υπηρεσίες | `promitheies_ypiresies.html` | Ανοικτός, απευθείας 118, ήσσονος αξίας 117Α, διαπραγμάτευση 32, εκτέλεση και παραλαβή |

Στατικός ιστότοπος. Δεν απαιτείται build ούτε εξαρτήσεις.

## Δομή

```
index.html                    αρχική οθόνη και σύγκριση των δύο πλαισίων
dimosia_erga.html             ενότητα Έργων
promitheies_ypiresies.html    ενότητα Προμηθειών και Υπηρεσιών
config.js                     διεύθυνση Supabase + δημόσιο κλειδί
cloud.js                      σύνδεση χρήστη και κοινοί φάκελοι υπηρεσίας
nav.js                        επιστροφή στην αρχική και εναλλαγή ενότητας
supabase/schema.sql           το σχήμα της βάσης (πίνακες, RLS, triggers)
supabase/ΜΕΤΑΦΟΡΑ.md          οδηγός μεταφοράς σε δικό του project
404.html  robots.txt  .nojekyll
```

## Δεδομένα

- **Χωρίς σύνδεση:** όλα μένουν στον φυλλομετρητή του χρήστη (`localStorage`).
- **Με σύνδεση:** κοινοί φάκελοι σε Supabase, ορατοί σε όλη την υπηρεσία.
  Πίνακες `esidis_folders` και `esidis_folder_log`, με RLS που επιτρέπει
  πρόσβαση μόνο σε ενεργά μέλη του πίνακα `esidis_profiles`.

Ο Οδηγός έχει **δικό του Supabase project και δικούς του χρήστες**. Δεν
μοιράζεται λογαριασμούς ούτε πίνακες με την εφαρμογή Προμηθειών ή με το ΥΔΕ.
Ολόκληρο το σχήμα ορίζεται στο [`supabase/schema.sql`](supabase/schema.sql),
ώστε το project να μπορεί να ξαναστηθεί από το μηδέν.

Το κλειδί στο `cloud.js` είναι *publishable* και προορίζεται να είναι δημόσιο.
Την προστασία των δεδομένων την κάνουν οι πολιτικές RLS στη βάση.

## Ενημέρωση

Αντικαταστήστε τα αρχεία με νεότερη έκδοση και κάντε commit. Το GitHub Pages
δημοσιεύει αυτόματα σε ένα με δύο λεπτά.
